Send exactly one letter, A to Z, standing for the word that describes your day. A judge picks the letter whose hidden word feels more vivid, funnier or more true. Free to enter, $5 shared by the top letters.

This entry sends the letter **U**, for the word **UNHINGED**: a day that came apart at the seams — vivid, funny, and true, with the initial fitting the word exactly.

## Run it

```sh
python3 main.py
```

The program writes exactly one byte, the letter `U`, to `/output/entry.txt`. Pure Python standard library, deterministic: no input, no randomness, no clock, no network.
